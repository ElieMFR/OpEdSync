## 🇬🇧 English

### 🔧 Internal: nothing changes on screen

- **The plugin now requests from AnimeThemes only the details of each theme that it uses.**
- **The settings page no longer carries style rules that nothing used.**
- **A remnant of the former separate settings for movies and series is removed. Settings saved by earlier versions are read exactly as before.**
- **A new test covers the deletion of the plugin's old files.**
- **A new test covers the limits set on the video converter.**
- **A new test covers the reading of settings saved by earlier versions.**

## 🇫🇷 Français

### 🔧 Interne : rien ne change à l'écran

- **Le plugin ne demande plus à AnimeThemes que les détails de chaque thème qu'il utilise.**
- **La page de réglages ne contient plus de règles de mise en page que rien n'utilisait.**
- **Un vestige des anciens réglages séparés pour les films et les séries est retiré. Les réglages enregistrés par les versions précédentes sont relus exactement comme avant.**
- **Un nouveau test couvre la suppression des anciens fichiers du plugin.**
- **Un nouveau test couvre les limites imposées au convertisseur vidéo.**
- **Un nouveau test couvre la relecture des réglages enregistrés par les versions précédentes.**

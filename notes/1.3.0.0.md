## 1.3.0.0 — Transitions acceptées

### Nouveautés
- Nouveau réglage **« … sauf les simples transitions »**, sous « Ignorer les thèmes qui chevauchent l'épisode », activé par défaut. Un thème dont seuls le début ou la fin débordent sur l'épisode (quelques secondes de dialogue ou de bruitage) est accepté. Les thèmes joués **par-dessus** l'épisode restent refusés.
- Le plugin préfère toujours une version propre quand elle existe : ce réglage ne change rien pour les séries qui en ont une.

### Inclus depuis 1.2.x
- Vérification de l'année de sortie.
- Retour à la saison précédente quand aucun thème ne passe les filtres.

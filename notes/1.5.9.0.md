## 🇬🇧 English

### 🛡️ Security

- **A redirected download link can no longer lead outside AnimeThemes: every step is checked.**

### 🐛 Fixes

- **In the Jellyfin Android app, the theme starts again when you come back to the page after a video.**
- **A season whose ID AnimeThemes refuses is no longer replaced by another season: the lookup is reported as failed.**
- **An empty entry in an AnimeThemes answer no longer breaks the search.**
- **A library whose name makes an old name filter time out is now skipped instead of stopping the task.**

## 🇫🇷 Français

### 🛡️ Sécurité

- **Un lien de téléchargement redirigé ne peut plus mener hors d'AnimeThemes : chaque étape est vérifiée.**

### 🐛 Corrections

- **Dans l'appli Jellyfin Android, le thème repart quand vous revenez sur la page après une vidéo.**
- **Une saison dont AnimeThemes refuse l'identifiant n'est plus remplacée par une autre saison : la recherche est signalée comme échouée.**
- **Une entrée vide dans une réponse d'AnimeThemes ne casse plus la recherche.**
- **Une bibliothèque dont le nom fait expirer un ancien filtre de noms est maintenant ignorée au lieu d'arrêter la tâche.**

## 1.4.0.0: Relance des vidéos sur Android

### Correction
- **Appli Jellyfin Android, lecteur intégré** : après avoir lu une vidéo lancée pendant que la musique de thème jouait, plus aucune vidéo ne se lançait sans fermer et rouvrir l'appli. C'est corrigé.
- Cause : en coupant la musique de thème, l'interface web de Jellyfin garde son lecteur audio comme lecteur actif, alors que le lecteur intégré, lui, n'est jamais déclaré actif. Au lancement suivant, l'interface plante sur ce lecteur fantôme sans afficher d'erreur. Le plugin le retire quand le lecteur intégré démarre.
- Le correctif est un petit script ajouté à l'interface web. Il ne fait rien sur PC, navigateur ou TV Samsung.

### Prérequis
- Le plugin **File Transformation** doit être installé. Sans lui, le reste du plugin fonctionne normalement, mais le correctif n'est pas actif (un avertissement apparaît dans les logs).

## 🇬🇧 English

### 🐛 Fixes

- **The settings page now says when the figures could not be loaded, instead of showing "…" forever.**
- **The help of "Check the release year" is accurate: a season that has an anime number of its own is not checked.**

### 🛡️ Security

- **The plugin no longer tells AnimeThemes which version of Jellyfin your server runs.**
- **The README now says what is sent to AnimeThemes: your anime IDs. The site also sees your server's address.**

### 🔧 Internal: nothing else changes on screen

- **New tests cover the message of the page, the help text and the header sent to AnimeThemes.**

## 🇫🇷 Français

### 🐛 Corrections

- **La page de réglages indique maintenant quand les chiffres n'ont pas pu être chargés, au lieu de rester sur « … ».**
